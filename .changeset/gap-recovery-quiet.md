**Fix: missing lines in the terminal — quiet-period gap recovery.** Two paths threw terminal output away on purpose and left nothing to repair the hole: `batchTerminalWrite()` queues live events while a buffer load runs and `_finishBufferLoad()` discards that queue, and `_onSessionTerminal()` drops frames once the render queues pass 128KB. The 128KB path did schedule a recovery, but on a fixed 2s timer that armed only once per burst — so it regularly fired while the session was still streaming, re-opening the gap it had just closed — and `_onSessionNeedsRefresh()` returned silently whenever a buffer load happened to be in flight, which threw the recovery away for good. Both now go through `_scheduleGapRecovery()`: the reload waits for output to go QUIET (`GAP_RECOVERY_QUIET_MS`, re-armed by every live frame), waits out an in-flight buffer load instead of dropping, and is floored at one reload per `GAP_RECOVERY_MIN_INTERVAL_MS` so a reload's own write window cannot chain into another. Bytes discarded during a load are counted (`_loadOverlapBytes`) so a recovery is armed only when something was actually lost, and a session switch drops a recovery armed for the session being left. Tests: `test/terminal-gap-recovery.test.ts`.
